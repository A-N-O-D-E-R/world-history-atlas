# World History Atlas

Atlas historique interactif mondial — carte + frise chronologique, 100 % statique.

- Spec MVP : `.scratch/world-history-atlas-mvp/spec.md`
- Tickets d'implémentation : `.scratch/wha-mvp-build/issues/`
- Vocabulaire : `GLOSSARY.md` · Décisions : `docs/adr/`

## Développement

```sh
pnpm install
pnpm dev        # serveur local
pnpm test       # tests
pnpm lint
pnpm build      # build statique dans dist/
```
