## Answer

Termes ajoutés à `GLOSSARY.md` : Route, Itinéraire.

- **Livré dans le MVP** :
  - couche **Routes antiques** : Itiner-e (CC BY 4.0) + AWMC (ODbL) en complément ;
  - **batailles animées** : points Wikidata qui apparaissent au fil de la lecture de la frise ; option **itinéraire schématique** reliant chronologiquement les batailles d'une même campagne (P361), pointillé, étiqueté « déduit — pas un tracé sourcé » ;
  - **migrations / routes commerciales médiévales et modernes** : modèle + couche + import via l'éditeur existent, couche livrée **vide** avec « aucune donnée libre disponible — contribuer ». Rien d'inventé.
- **Modèle** : *Route* = ligne + intervalle de validité + Source + certitude par tronçon. *Itinéraire* = suite ordonnée d'étapes datées (Événements ou points sourcés), marqué *sourcé* ou *déduit*.
- **Certitude Itiner-e → Fiabilité** : certain → moyenne ; conjecturé → approximative ; hypothétique → approximative + pointillé.
- **Tronçons non datés (~81 %)** : affichés sur toute la période couverte par Itiner-e, mention « datation inconnue — période couverte par Itiner-e », Fiabilité forcée à approximative.
