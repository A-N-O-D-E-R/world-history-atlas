## Question

Existe-t-il des données **redistribuables** pour les routes commerciales, les migrations et les mouvements de batailles (tracés, dates, acteurs), au moins pour l'Europe occidentale / France ? Pour chaque source : contenu, géométrie (ligne, points datés), granularité temporelle, licence. Si rien d'exploitable sans digitalisation manuelle, le dire clairement.

## Answer

Partiellement. Données redistribuables trouvées :
- **Réseaux antiques (France incluse)** : Itiner-e (routes romaines, lignes, dates `Lower/Upper_Date` sur ~19 % seulement, certitude par tronçon, **CC BY 4.0**) ; AWMC geodata (routes, **ODbL**) ; ORBIS (maillage routes/fleuves/mer vers 200 CE, **MIT**).
- **Médiéval / moderne** : Viabundus (1350-1650, lignes + nœuds, CC BY 4.0 selon Zenodo / CC BY-SA selon la description) **ne couvre pas la France**.
- **Batailles** : Wikidata (**CC0**), **points datés** seulement : ≥578 batailles en France avec coordonnées et date, 142 avec participants. Les mouvements ne peuvent être qu'inférés (chaîne chronologique par campagne P361), pas des tracés sourcés.
- **Migrations, flux commerciaux, tracés de campagnes** : **rien d'exploitable sans digitalisation manuelle**. DARMC et SlaveVoyages ont des licences non vérifiées.
