# 35: Éditeur local — attributs

**What to build:** Le mainteneur corrige une Fiche via l'assistant central et obtient un fichier de surcharge écrit en local.

**Blocked by:** 12 (Surcharges)

**Status:** ready-for-agent

- [ ] Bouton « Proposer une correction » sur chaque Fiche
- [ ] Fenêtre centrale, étapes cliquables Champs → Dates → Géométrie → Source → Envoi ; champs modifiés surlignés
- [ ] Saisie de Date (valeur, précision, calendrier, intervalle) avec refus de l'année 0 et des incohérences
- [ ] Source obligatoire (titre + licence de la liste blanche)
- [ ] Mode local : écriture du fichier de surcharge, validé par le build
- [ ] Mobile : même assistant plein écran
